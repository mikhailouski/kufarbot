# KufarBot

Telegram-бот для отслеживания **новых** объявлений на kufar.by в указанных разделах.
Когда в отслеживаемом разделе появляется новое объявление, бот присылает его
краткое описание (заголовок, цена, город) со ссылкой и фото.

## Как это работает

1. Вы присылаете боту ссылку на раздел kufar.by с нужными фильтрами, например:
   ```
   /watch https://www.kufar.by/l/fotoapparaty/ft~fujifilm?prc=r:100000,100000000000&sort=lst.d
   ```
2. Бот открывает эту ссылку и честно вытаскивает из страницы ровно те параметры поиска,
   которые использует сам сайт (категория, подкатегория, цена, марка, сортировка и т.п.).
3. При подключении раздела бот делает «baseline» — **не рассылает** уже существующие
   объявления, а только те, что появятся после.
4. Каждые `CHECK_INTERVAL` секунд бот опрашивает раздел и присылает администратору
   новые объявления (по количеству новых `list_id`; без повторов, даже после перезапуска).

## Уведомление

```
📷 Fotoapparat Fujifilm x-t50
💰 3500 р. (≈1176 USD)
📍 Минск, Центральный
🔗 Открыть объявление
```
+ первое фото объявления.

## Установка и запуск (Windows / PowerShell)

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env   # заполните BOT_TOKEN и ADMIN_USER_ID
python main.py
```

## Настройка

В `.env`:
| Переменная | Описание                                                                 |
|------------|---------------------------------------------------------------------------|
| `BOT_TOKEN` | токен бота от @BotFather                                              |
| `ADMIN_USER_ID` | Telegram user id владельца — только он управляет ботом и получает сообщения |
| `CHECK_INTERVAL` | интервал опроса, сек (по умолчанию 60)                                |
| `CHECK_SIZE` | сколько объявлений брать за опрос раздела (по умолчанию 50)             |
| `MAX_SEND_PER_CHECK` | максимум уведомлений за один цикл (по умолчанию 15)                  |

## Команды

- `/start` — помощь
- `/watch <ссылка>` — начать отслеживать раздел (с фильтрами из ссылки)
- `/list` — список отслеживаемых разделов
- `/pause <номер>` — пауза / возобновление
- `/un <номер>` — удалить раздел

## Структура

```
main.py            # запуск, фоновый цикл мониторинга
config.py          # чтение .env
storage.py         # JSON-хранилище: цели + отправленные list_id
bot/
  handlers.py      # команды бота
  notifier.py      # форматирование уведомлений
kufar/
  client.py        # запросы к внутреннему API kufar
  urlcast.py       # декодер ссылок kufar => параметры API (через __NEXT_DATA__)
  models.py        # модель объявления
```

## Примечание по API

Проект использует неофициальный JSON API, которым пользуется сам сайт
(`cre-api.kufar.by/ads-search/v1/.../rendered-paginated`). Эндпоинт может меняться.
Используйте умеренно, чтобы не создавать нагрузку на сайт.
